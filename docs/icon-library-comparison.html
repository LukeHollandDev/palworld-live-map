Icon library replacement study

A direct comparison of every custom map glyph and interface icon currently used by Palworld Live Map. The proposed icons are real assets from each library, shown in the app’s dark-map treatment and category colours.

17 map markers 9 UI controls 3 free libraries 78 mapped alternatives
Recommended starting point

Tabler Icons

It has the most convincing semantic matches for the map-specific categories while retaining the crisp technical style of the current interface. Use the React package with named imports, and preserve map legibility with a subtle line shadow rather than a backing shape.

Shortlist

Free, production-ready choices

Counts and licences were checked against each project’s official site/repository. “Phosphor assets” includes its six visual weights; it represents roughly 1,500 icon concepts rather than 9,072 unique concepts.

Tabler wins on landmark specificity

Building Warehouse, Building Factory, Tower, Building Arch and Building Monument are unusually strong matches.

Phosphor wins at the smallest scale

The bold weight remains readable at 20px without increasing a global stroke width or editing paths.

Two categories still need product judgement

Companion Pal and Ancient Shrine pickup have no literal library icon; heart-handshake and sparkle are semantic stand-ins.

1:1 replacements

Interface and control icons

Replacing these from the same chosen library removes the current mixture of hand-drawn SVG, Heroicons, Octicons and text glyphs.

This gallery uses Iconify’s official web component only to make the standalone comparison easy to review; it fetches the selected SVG data at runtime. A production change should import named React components directly from the chosen library, so the app has no Iconify runtime or third-party API dependency.
